# Exact retained RAW–XMP date-test admission method

This authored method defines the bounded #0184 review. Actual candidate selection,
rights decisions, identities and outcomes belong in restricted local evidence.
This document contains no media-derived observations or admission result.

## Select before opening media

Read the retained inventory and fixture manifests as text. Order existing XMP
fixture records by their recorded fixture ID using ordinal string order; select
the first record whose explicit parent lineage names a retained full-RAW fixture.
Record that rule and the exact selected records privately before any media access.
Do not infer pairing from filenames or acquire another candidate to obtain a pass.
The [explicit path resolver](pairing.md) supplies a later bounded physical-file
observation, not evidence that metadata describes the same image.

## Separate authority from technical eligibility

For both selected artifacts, bind the exact manifest revision, recorded hash and
length, provenance decision, original grant, privacy restrictions and derivation
recipe. Preserve historical records. Review analysis, derivative creation and
report publication rights separately. A sidecar inherits its source restrictions;
its existence does not grant a new test phase. Check `allowedPhases` together with
purpose restrictions and any exact scoped permission overlay. A grant for another
assertion, output type or fixture cannot authorize this use by analogy.
Historical reference-only eligibility is not itself evidence of missing owner
consent. When the existing grant covers private analysis and separately named
test derivatives, the authorized reviewer evaluates technical eligibility and
records a scoped new decision without changing historical records or asking the
owner to repeat that grant. A failed technical prerequisite keeps differential
execution unadmitted.

Distinguish reference characterization from differential execution of the native
date adapter and independent derivative comparison. Register every proposed output
separately: immutable RAW input, immutable retained XMP input, separately named XMP
candidate, reference comparison output and private report. Each derivative needs
the parent identity, exact recipe/tool binding, intended phase and inherited access
restrictions. Broad modification permission never makes received originals targets.

Only after the precise proposed inspection is authorized may the reviewer open or
hash media. A historical recorded hash is not a fresh immutable observation or a
live identity hold. If authority fails first, retain that exact refusal and state
which later checks were not run. Do not present lack of access as a technical
packet refusal or claim a fresh before/after preservation measurement.

## Apply the existing technical contracts

For an authorized invocation, bind the actual bytes and RAW variant evidence,
then apply the [production packet profile](packet-profile.md), exact singleton
target, and [original-date mapping](date-mapping.md). Read-only packet inspection
and edit constraints are separate checks. Unknown application semantics are not
cleared by syntax success. Apply the [native adapter's](native-date-adapter.md)
CMT2 coverage, companion-path, date and size restrictions without weakening them
to admit the selected input. Bind original snapshots and record any exact refusal.

Before derivative execution, retain explicit conflict/loss choices and the
source-specific impact review. Successful admission for a bounded private test
does not authorize publication, existing-target replacement, RAW mutation or a
storage profile. Those remain independent downstream requirements.

## Retain a finite decision

The private record must say admitted or refused for the exact proposed use,
identify the controlling evidence and distinguish unrun checks from failures.
Verify text-record evidence bindings and lineage independently. When media access
was authorized, retain actual source-retention observations and their limits;
otherwise state that no media was opened and no fresh preservation claim exists.
Keep camera-derived reports, outcomes, counts and identifiers out of tracked files
when their grants deny publication. Public verification covers this authored
method and permitted authored controls only.

If an actual owner-permission premise is missing after independent review, prepare a
narrow question naming the private selection record and bounded phase, derivative
and report controls. Explain the concrete use absent from the existing grant;
a historical phase label alone is insufficient. An answered question still requires the technical
checks above; refusal evidence never substitutes for positive downstream evidence.
